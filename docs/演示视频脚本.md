## 第 1 幕：痛点（0:00-0:40）

**画面**：Hardmind 导出数据截图（UCLA 57 vs 61）+ 高亮其提示词两行。

**旁白**：

直接告诉模型该答什么。测的不是心理，是提示词服从度。"

## 第 2 幕：方法（0:40-1:20）

**画面**：docs/figures/d2_blind_protocol.png（盲测协议图）。

标签，真值只用于校验，绝不进提示词；前后测文本完全一致。"

## 第 3 幕：四场演示（1:20-2:40）

**画面**：d1_four_fields.png → 依次 fig1 / fig6 / fig7 / fig8。

**旁白**：
"第一场，量场：已知组效度、重测信度、仿真保真度——量表恢复了区分能力。
第二场，考场：同一批灵魂在中英双语下施测，我们发现症状量表在中文语境
系统性高报——文化测量不等价，是可以定位到条目的。
第三场，炼场：C-SSRS 分级剧本危机评测，双通道评分给出安全评分卡——
没有安全证据的心理产品不该上线。
第四场，预演场：给用户画像建数字孪生，A/B 干预先在你分身上试，
剂量-反应曲线决定推荐哪一臂。"
