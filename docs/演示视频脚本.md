## 第 1 幕：痛点（0:00-0:45）

**画面**：屏幕录制 Hardmind 项目导出数据
conversations/chat_20260521_100103.md 中两段 UCLA 分数截图（57 分 vs 61 分，
均为 High）。

**旁白**：
"心理健康行业最大的基础性瓶颈，是心理状态难以量化。这是开源项目
Hardmind 的真实导出数据：设定完全相反的两个 AI 角色——孤独学生和
开朗学生——前测 UCLA 都是高分。为什么？因为它的测评提示词直接告诉
模型该答什么。测的不是心理，是提示词服从度。"

**画面**：高亮 app.py 中前测/后测提示词的两行原文。

**旁白**："AI 心理产品的'心理状态'和'疗效'，今天没有一把可验证的尺子。"

## 第 2 幕：方法（0:45-1:30）

**画面**：psybench 代码目录树 + souls.py 中"陈屿"人设节选。

**旁白**：
"心镜 PsyBench 的回答是：把大模型 Soul 变成可重复、可标定真值的
数字心理被试。人设只写经历、不贴标签；它的目标心理状态区间——真值——
被声明在另一个字段里，只用于事后校验，绝不进入提示词。"

**画面**：assessment.py 盲测协议 prompt 高亮 + 量表库五张量表名称。

**旁白**："施测时使用中性问卷说明，前后测文本完全一致。然后用
Cronbach α、ICC、已知组效度、保真度、配对 t 检验——经典心理计量学
指标——来验证'量得准不准'。"

## 第 3 幕：实验演示（1:30-2:30）

**画面**：终端运行命令并实时滚动日志：
    python -m psybench.run --provider ollama --model qwen2.5:7b
    --out psybench/results_qwen25_7b --e1-sessions 5
    --e3-sessions 3 --rounds 6

**旁白**：
"四组实验全自动运行：E1 用四名不同心理状态的大学生 Soul 各做
5 次独立盲测，检验已知组效度与重测信度；E3 对高孤独 Soul 做三臂
对照——陪伴对话、中性问答、独自书写——前后测检验干预反应度；
E4 检验作答漂移的校正方法。全程本地运行，数据不出本机，支持断点续跑。"

## 第 4 幕：结果（2:30-3:30）

**画面**：依次展示 figures/ 中四张图（已知组效度、干预前后测、
保真度、信度指标）+ 结果报告.md 关键表格。

**旁白**：
"看图说话：第一张，四名 Soul 的实测分数与声明真值区间——高低孤独组
的差异清晰且统计显著（p=0.0002）；第二张，三臂干预的 UCLA 前后测——
修复测量污染后，短程干预没有显著差异，而这恰恰说明平台能否决单次
小样本的伪阳性结论；第三张，仿真保真度散点；第四张，信度指标。"
