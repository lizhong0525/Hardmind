# 佐证材料清单（按官方要求合并为一份 PDF 提交）

## 1. 作品真实性与原创性证据

- 全部实验由本团队在 2026-08-25 于本地机器完成，原始日志见
  psybench/results_qwen25_7b/run_meta.json（含起止时间、耗时 618.5s、后端与温度参数）；
- 条目级原始作答（含每次施测的完整模型输出 raw 字段）见
  e1_known_groups.json / e3_intervention.json / e4_calibration.json；
- 对话干预的全部逐轮记录见 e3_intervention.json 中每个会话的 transcript 字段。

## 2. 创新性证据（对比与实证）

- 评估对象 Hardmind 的缺陷证据：
  - 源码提示词污染：app.py（build_ucla_assessment_prompt 中前/后测的
    "generally okay" 与 "heartwarming conversation" 预置结论文本）；
  - 实测数据失效：conversations/chat_20260521_100103.md 记录 UCLA 前测
    Chen Yu=57、Lin Xiaohan=61（两个设定相反角色同为 High）；
- 本平台修复效果的对比证据：同样「一孤独一开朗」设定下，盲测协议测得
  UCLA 53.6 vs 36.8，Welch t=6.86，p=0.0002，d=4.34（见 results_qwen25_7b/
  结果报告.md 第 1 节）。

## 3. 应用成效证据（数据详实性）

- E1：4 Soul × 3 量表 × 5 次独立盲测 = 60 次标准化施测，全部已知组对照显著；
- E3：3 条件 × 3 会话 = 9 个干预会话（含 54 轮对话）。修复测量污染后
  重跑显示：6 轮轻量干预在 n=3 下无显著组间差异（UCLA 三臂 |Δ|≤2.0 分，
  p 均>0.05），说明该框架能可靠否决单次小样本的伪阳性结论（旧缺陷数据
  曾出现 p=0.024 的伪显著差异，修复后消失）；
- E4：作答风格校正对照实验 96 次施测（见 e4_calibration.json 与报告第 3 节）；
- 全部统计量（α、ICC(2,1)、Welch t、Cohen d/dz、配对 t、95% CI、
  Spearman ρ）由 psybench/psychometrics.py 计算，公式见源码注释，
  可独立复核。
