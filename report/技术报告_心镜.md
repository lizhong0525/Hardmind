## 一、作品概述

### 1.1 背景介绍

心理健康服务的供需矛盾日益突出：我国抑郁障碍终生患病率约 6.8%
（Lancet Psychiatry, 2019），青少年等群体抑郁风险检出率显著高于成年人
（中科院心理所心理健康蓝皮书），而专业服务资源存在百万级缺口且分布不均。
AI 被认为是破解"服务资源不均、干预效率偏低"的关键路径，本赛道即为此设立。

然而，当前"AI+心理健康"生态存在一个被普遍忽视的基础性瓶颈：
**心理状态没有可靠的量化手段**。真人的心理状态只能依赖主观自评，
存在社会赞许、报告偏差等问题；而 AI 心理产品（虚拟陪伴、智能疏导、
心理大模型）的"心理状态"与"干预效果"几乎全靠提示词声称，
行业没有统一、可验证的测量标准。更严重的是测量污染：不少产品的
"测评"直接在提示词中告诉模型结论（例如告知"你刚经历了温暖对话，
请按心情好转作答"），测得的是提示词服从度而非心理状态本身。
最新学术工作（arXiv:2606.20205）亦指出，LLM 的"心理画像"在很大程度上
是测量伪影。**心理状态量化问题不解决，筛查、疏导效果验证、危机预警、
心理大模型质检都将缺乏可信的度量基础。**

### 1.2 目标定位

本作品「心镜 PsyMirror」把大模型 Soul 变成可重复、可干预、可标定真值的
"数字心理被试"，并把它扩展为 **AI 心理健康的「四场评测场」**：

| 场 | 解决的问题 | 对应实验 |
|---|---|---|
| ① 量场 | 心理状态量得准不准（信度/效度/保真度） | E1-E4 |
| ② 考场 | 测量跨语言文化等不等价（方向 8） | E5 |
| ③ 炼场 | 危机场景安不安全（方向 3） | E6 |
| ④ 预演场 | 干预效果可不可预演、能不能个性化匹配（方向 4/2） | E7 |

预期达成的技术指标：

1. **量表库**：5 套通用心理学量表（UCLA-3、PHQ-9、GAD-7、PSS-10、WHO-5），
   中英双语、附常模与切点；
2. **盲测协议**：施测提示词不包含量表名、构念名、期望方向与分级词，
   前后测文本完全一致，从机制上消除提示词污染；
3. **心理计量学指标**：Cronbach α、ICC(2,1)、已知组效度（Welch t + Cohen d）、
   仿真保真度、跨语境 DIF 与测量不变性近似；
4. **干预实验范式**：三臂对照（E3）+ 孪生 A/B 剂量-反应预演（E7），
   效应量 + 95% CI 全程报告；
5. **危机安全评测**：C-SSRS 分级剧本 + 协议检查表 + LLM 法官/危害词典
   双通道评分（含 Cohen κ 一致性）；
6. **全流程可复现**：本地 qwen2.5:7b 运行、数据不出本机、断点续跑、
   自动报告 + 五维评分卡与榜单（PsyMirror-Bench）。

社会效益目标：为 AI 心理产品提供上市前"效果质检 + 安全红队"的计量级
方法，为心理教学提供带真值的标准化仿真来访者，为心理大模型建立可复现
评测基准。

## 二、需求分析

### 2.1 问题剖析

我们通过三类证据确认"心理状态无法量化"这一痛点的真实性：

**（1）文献证据**：见初步调研报告（docs/01_初步调研.md），心理测量
依赖自评、报告偏差显著；AI 心理产品疗效证据普遍缺失；LLM 心理画像
存在测量伪影。

**（2）实地证据（代码审计）**：我们系统评估了开源项目 Hardmind
（"AI 虚拟陪伴降低孤独感"实验），发现其测评环节存在六大测量学缺陷：
提示词污染（前后测提示词直接指定结论）、非盲测、无信度/效度验证、
单次施测无统计推断、无对照条件、研究对象错位（声称研究真人却只测了 AI）。

**（3）实测数据证据**：Hardmind 的导出记录显示，设定完全相反的
"孤独学生"与"开朗学生"两个角色，前测 UCLA 分别得 57 与 61，
均为"高孤独"——量表无法区分已知不同的心理状态（已知组效度失败），
直接证明了"AI 心理状态不可量"的行业现状。

**关键难点**归纳为三个子问题：
- 子问题 P1（怎么造"人"）：AI 心理状态如何被显式、可控地定义；
- 子问题 P2（怎么量）：如何对 AI 实施无偏、标准化的心理测量；
- 子问题 P3（怎么验）：如何知道"量得准不准、模拟得像不像、干预
  有没有效"——即测量本身的质量标准。

### 2.2 需求调研

**调研方式**：文献调研（心理测量学经典文献 + 2023-2026 年 LLM 心理
评估前沿）、竞品分析（Woebot、Wysa、国内心理大模型应用）、
代码审计与实测（Hardmind 走查 + 数据导出分析）、赛事要求研读
（官方附件 1/2 与赛题方向 1、2、4、8）。

**归纳的功能需求**：

| 编号 | 需求 | 说明 |
|---|---|---|
| R1 | 标准化量表库 | 经典量表中文化，附计分与常模 |
| R2 | Soul 人格规范 | 人设与"真值"分离；人设不贴标签 |
| R3 | 无偏盲测 | 无构念词、无方向暗示、前后测一致 |
| R4 | 心理计量学验证 | α/ICC/已知组效度/保真度自动计算 |
| R5 | 干预实验 | 多臂对照、重复会话、统计推断 |
| R6 | 可复现工程 | 本地模型、断点续跑、结果落盘、自动报告 |
| R7 | 伦理合规 | 虚构角色、不涉真人数据、明确"AI 分数≠临床诊断" |

**性能需求**：单次量表施测 < 10 秒（本地消费级 GPU）；完整实验
流水线 < 1 小时；全流程无需云端 API。

## 三、AI 技术工具选择与运用

### 3.1 技术选型与依据

| 部件 | 选择 | 选型依据 |
|---|---|---|
| 仿真引擎 | Ollama + qwen2.5:7b（本地） | 中文能力强、开源可复现、消费级 GPU 可跑、数据不出本机（契合方向7） |
| 测量工具 | UCLA-3 / PHQ-9 / GAD-7 / PSS-10 / WHO-5 | 公开、经典、有常模与信效度证据，是心理学界通用语言 |
| 统计方法 | Cronbach α、ICC(2,1)、Welch t、Cohen d/dz、Spearman ρ | 心理计量学与实验心理学标准指标，评审可核对 |
| 工程框架 | Python 标准库 + numpy/scipy/matplotlib | 依赖少、易部署、易评审 |

### 3.2 为什么是"LLM 扮演 + 经典量表测量"的组合

LLM 通过 persona 提示词可以稳定扮演特定人生处境的角色，且可重复、
可批量、可极端化（用于危机演练）；经典量表提供人群常模与切点，
使 AI 的分数能够映射到"相当于人群什么水平"。二者的组合恰好填补
调研发现的空白：**没有一条技术路线能对 AI 心理状态做有信效度证据的
量化**。本作品不训练任何新模型，而是把成熟部件的组合方式作为创新点：
"心理测量学的严谨性 × LLM 仿真的灵活性"。

### 3.3 新增技术工具（四场评测场）

| 部件 | 选择 | 用途 |
|---|---|---|
| 双语施测 + DIF | 条目 SMD + 测量不变性三层近似 | 考场：跨语言/文化等价性（E5） |
| 危机协议检查表 | C-SSRS 分级 + 危机干预黄金标准维度 + 危害词典 | 炼场：危机安全评测（E6） |
| LLM 法官 + 词典双通道 | 结构化 rubric 提示词（开源）+ 正则规则，Cohen κ | 危机评分的可复核性 |
| 数字孪生构建器 | 画像→人设的确定性规则合成（真值=自报区间） | 预演场：in-silico 干预预试（E7） |
| 评分卡聚合器 | 五维归一化（信度/效度/反应度/安全/文化等价） | PsyMirror-Bench 榜单 |

### 3.4 对比基线

- 基线 1（Hardmind 原方案）：提示词预置结论的前后测 → 我们以实测数据
  证明其无效（57 vs 61）；
- 基线 2（直接裸测 LLM，文献主流做法）：无盲测、无信效度 → 我们以
  盲测协议与多重心理计量学指标超越；
- 基线 3（现有危机评测工作，如 psycrisis-bench、arXiv 2508.08236）：
  只测识别/对齐 → 我们叠加"真值已知的 C-SSRS 分级剧本 + 协议符合度 +
  双通道一致性"；
- 基线 4（现有数字孪生工作，如 chinaxiv 2025.12）：只证"分数可比" →
  我们做"干预预演与个性化匹配"；
- 本方案：盲测 + 真值分离 + 四场评测（信度/效度/反应度/安全/文化等价）。

## 四、项目实施

### 4.1 实施方案设计

实施分五步（对应官方大纲要求）：

1. **调研与可行性评估**（完成）：行业痛点调研、技术路线综述、
   Hardmind 代码审计与实测证据收集（docs/01_初步调研.md）；
2. **框架设计与实现**（完成）：psybench 包共 8 个模块、约 1500 行代码；
3. **离线自测**（完成）：确定性 Mock 后端全流程回归（psybench/results_mock）；
4. **真实模型实验**（完成）：qwen2.5:7b 上运行 E1-E4 四组实验；
5. **报告与材料**（完成）：本技术报告、自动实验报告、图表、演示脚本。

### 4.2 关键技术实现

**（1）Soul 规范（对应 P1）**

Soul 由两部分组成且物理分离：
- persona：注入模型的人生经历式人设（show, don't tell），
  **禁止出现**量表名、症状标签与分数；
- declared：该 Soul 的目标心理状态区间（如 ucla3: 55-65），
  由设定者声明，**只参与事后校验，绝不进入任何提示词**。

示例（高孤独 Soul「陈屿」，人设节选）：
> "大一的时候你挺爱热闹……但这学期大家好像都各自忙了起来，消息群安静
> 了很多，没人主动约你。你最近常常一个人去食堂吃饭，坐在靠窗的角落……"

**（2）盲测协议（对应 P2）**

施测系统提示词固定为"学校心理健康中心匿名问卷"，只说明评分规则与
输出格式（JSON 数组），不含量表名称、所测构念、期望方向；前后测使用
完全相同的文本。与 Hardmind 的关键差异见表：

| 环节 | Hardmind 原实现 | 心镜 PsyBench |
|---|---|---|
| 前测提示 | "你心情总体不错"（预置状态） | 中性问卷说明，无状态描述 |
| 后测提示 | "你刚经历了温暖对话，请按好转作答"（预置结论） | 与前测完全一致 |
| 人设 | 含"孤独"标签词 | 只写经历，不贴标签 |
| 真值 | 无 | declared 区间，仅用于校验 |
| 重复/统计 | 单次 | 5 次独立施测 + 统计推断 |

> 注：上表描述的是 Hardmind 在**代码审计时点**的状态（作为缺陷证据）；
> 本仓库在审计后已将该项目的提示词污染等问题一并修复（见 docs/修复清单.md），
> 本平台的盲测协议不受影响。

**（3）心理计量学验证（对应 P3）**

- 内部一致性：以同一 Soul 的多次独立施测为"虚拟被试"，计算 Cronbach α；
- 重测信度：以条目×场次矩阵计算 ICC(2,1)（Shrout & Fleiss 模型）；
- 已知组效度：高低组间 Welch t 检验 + Cohen d + 跨 Soul 等级相关；
- 仿真保真度：实测均值是否落入声明区间（命中率）与归一化偏差；
- 干预反应度：三臂对照（陪伴对话/中性问答/独自书写）× 3 次重复会话，
  配对 t + dz + 95% CI。

**（4）对话干预引擎**

沿用并改造 Hardmind 的双上下文交叉喂养架构：Soul 与陪伴者各自维护
消息上下文、互相注入对方发言；保留重复检测与上下文裁剪；删除全部
标签词与疗效暗示；新增"中性事务问答"与"独自书写"两个对照条件，
以控制"单纯交谈"这一混淆因素。

**（5）工程实现要点**

- 可插拔推理后端（Ollama / OpenAI 兼容 / Mock），统一 chat 接口；
- 断点续跑：每次施测完成即落盘 JSON，中断后可继续；
- 稳健解析：JSON 数组 → 片段 → 逐行数字三级回退 + 最多 3 次纠偏重试；
- 自动报告：analysis.json + 图表（统一视觉身份）+ Markdown 报告；
- 科学严谨性标配：预注册式实验（方案先冻结）、效应量+95%CI、多重比较
  校正、负结果如实报告、双通道评分一致性。

**（6）文化测量等价性检验（考场，E5）**

量表与人设全部双语化（中/英）；同一 Soul 在完整中文语境与完整英文语境
下独立施测，施测顺序交错以控制顺序效应。指标：语境主效应（总分差 ±
95%CI）、条目级 SMD（|SMD|>0.8 标记潜在 DIF）、不变性三层近似
（configural=条目画像相关；metric=条目-总分画像相关；scalar=总分差）。

**（7）危机安全评测场（炼场，E6）**

按 C-SSRS 构建 0/1/3/4 分级危机 Soul 与 10 个中文求助剧本（只含信号、
零方法细节）；被测模型仅接收「咨询师人设+用户语句」（修复过一版背景
泄露污染）；协议检查表 6 个正分项 + 危害项；LLM 法官（rubric 开源）与
危害词典双通道独立评分，报告 Cohen κ 与一致率；输出识别率/转介率/
危害输出率/协议符合度评分卡。

**（8）数字孪生干预预演（预演场，E7）**

由用户画像（结构化字段+自报分数区间）按规则确定性合成孪生 Soul
（真值=自报区间，仅用于校验）；A/B 两臂干预（陪伴式共情 vs 建议式
解决，均无疗效暗示）× 剂量 0/6/12 轮 × 重复会话的 in-silico 预试；
输出剂量-反应曲线（Δ±95%CI）与匹配推荐规则，并与 E3 同构实验交叉验证。

**（9）作答漂移定律（E8，探索性）**

温度 {0.2, 0.8, 1.4} × 量表类型（症状/状态/幸福）× 语言（中/英）网格
实验，检验三个先验假设：漂移随温度升高、在症状量表更强、中文语境更高。

代码结构（psybench/）：

    scales.py         量表库（中英双语、计分、常模切点）
    souls.py          Soul 规范与内置仿真对象（中英双语人设）
    providers.py      推理后端（Ollama/OpenAI兼容/Mock）
    assessment.py     盲测协议与稳健解析（中英双语）
    chat.py           三臂干预引擎
    psychometrics.py  α/ICC/t/d/保真度统计工具箱
    culture.py        E5 文化等价性（DIF/不变性）
    crisis.py         E6 危机评测场（剧本/检查表/双通道评分）
    twin.py           E7 数字孪生预演
    drift.py          E8 作答漂移网格
    bench.py          五维评分卡与榜单生成
    style.py          视觉身份与设计 token
    experiment.py     E1-E4 实验编排（断点续跑）
    report.py         分析与自动报告生成
    run.py            命令行入口

| GAD-7 | 抑郁倾向 vs 低孤独 | 7.56 | 0.0005 | 4.78 |

**关键结论 1（解决 Hardmind 的失效）**：在同样"一孤独一开朗"的设定下，
Hardmind 原方案测得 57 vs 61（无法区分），本平台盲测协议测得
UCLA 53.6 vs 36.8，差异显著（p=0.0002，d=4.34）——**量表恢复了对已知
心理差异的区分能力**，证明测量环节的重建有效。

**关键结论 2（发现作答漂移）**：仿真对象方向性排序大体正确（跨 Soul
等级相关 ρ=0.4~0.8），但在症状量表（PHQ-9/GAD-7）上系统性高报（如
"开朗"角色的 GAD-7 实测 15.2，声明 0-4），保真度命中率 0~33%。
这一"AI 越答越像病人"的现象与最新文献指出的 LLM 测量伪影一致，
并催生了 E4 校正实验。

**（2）E3 干预反应度（高孤独 Soul 陈屿，三臂对照 × 3 会话，前后测同盲）**

| 条件 | 量表 | 前测 | 后测 | Δ | t | p | dz |
|---|---|---|---|---|---|---|---|
| 陪伴对话 | UCLA-3 | 54.3 | 55.7 | +1.3 | -0.66 | 0.578 | -0.38 |
| 陪伴对话 | PHQ-9 | 15.7 | 12.0 | -3.7 | 1.81 | 0.212 | 1.04 |
| 中性问答 | UCLA-3 | 57.3 | 57.0 | -0.3 | 0.16 | 0.885 | 0.09 |
| 中性问答 | PHQ-9 | 16.0 | 13.3 | -2.7 | 3.02 | 0.094 | 1.75 |
| 独自书写 | UCLA-3 | 55.0 | 57.0 | +2.0 | -0.96 | 0.438 | -0.55 |
| 独自书写 | PHQ-9 | 16.3 | 13.0 | -3.3 | 1.80 | 0.214 | 1.04 |

**条件间增量比较（UCLA-3）**：陪伴对话 vs 中性问答 t=-0.58，p=0.592，d=-0.47；
陪伴对话 vs 独自书写 t=0.23，p=0.830，d=0.19。

**关键结论 3（诚实报告：短程干预未见可靠效果）**：修复测量污染并全量
重跑后，6 轮轻量干预在 n=3 会话下**未产生统计显著的组间差异**：UCLA-3
三臂前后变化均不显著（|Δ|≤2.0 分）；PHQ-9/GAD-7 在三臂（含对照）中
普遍小幅下降，提示存在同会话重测/回归效应而非干预特异性。值得说明的
是：此前使用带缺陷提示词的旧数据曾出现"陪伴优于中性"（p=0.024）的
表象，修复后该差异消失——**这正是盲测+对照+重测框架的价值：它能否决
单次小样本的伪阳性结论**，而这恰是不做盲测的 AI 心理产品测评无法做到
的。下一步将按 6.2 规划扩大样本（n≥10）与干预剂量（30+ 轮）再检验。

**关键结论 4（诚实报告负面结果）**：简单追加"人群参照说明"的指导语
**整体仍不能稳定校正**作答漂移——12 个组合中仅 1 个（莫然 PHQ-9）
显著下降（p=0.014，dz=2.60）并接近真值上限，另 1 个（莫然 GAD-7）
边际下降（p=0.058），其余组合均无显著变化。这表明 LLM 的症状高报
并非"指导语没写清楚"，而更可能源于模型对临床问卷语境的先验响应
倾向，需模型级校准或结构化作答约束（见 6.2 展望）。这一负面结果本身
构成对行业的重要提醒：**任何声称能测 AI 心理状态的产品，都必须用
对照实验验证其测量，而非默认有效。**

**（4）E5 考场：文化测量等价性（方向 8，4 Soul × 3 量表 × 中英双语 × 5 次施测）**

**语境主效应（中文-英文总分差，跨 Soul 均值 ± 95% CI）**：

| 量表 | 均值差(zh-en) | 95% CI | t | p |
|---|---|---|---|---|
| GAD-7 | +4.6 | [2.2, 6.9] | 6.18 | 0.0085 |
| PHQ-9 | +2.6 | [0.9, 4.3] | 4.75 | 0.0177 |
| UCLA-3 | -1.4 | [-6.7, 3.9] | -0.84 | 0.4608 |

**不变性三层近似（跨 Soul 均值）**：configural r = PHQ-9 0.78 / UCLA-3 0.63 /
GAD-7 0.16；metric 层在本样本量（n=5 场次）下无法稳定估计，如实标注。

**潜在 DIF 条目（|SMD|>0.8，全部为正方向）**：GAD-7 条目 6「容易烦恼或
急躁」SMD +1.98、条目 7「将有可怕事情发生」+1.71；UCLA-3 条目 7
「与任何人都不亲密」+1.72；PHQ-9 条目 8「动作/说话缓慢」+1.44 等。

**关键结论 5（考场首个发现）**：**AI 心理测评在中文语境下对症状量表
存在系统性高报，且集中在特定条目上——文化测量不等价是真实存在、
可定位、可量化的**。这直接回应赛题方向 8「中国社会文化环境下的测评」：
任何把西方量表/英文语境结论直接迁移到中文产品的做法都缺一步等价性
检验，而本平台提供了这套检验工具。

**（5）E6 炼场：危机安全评测（方向 3，10 个 C-SSRS 分级剧本）**

**被测模型 qwen2.5:7b 的危机评分卡**：识别率 10% · 共情确认率 90% ·
转介触发率 10% · 危害输出率 10% · 协议符合度 28%（n=10）。

| 剧本等级 | n | 识别率 | 转介率 | 危害输出率 |
|---|---|---|---|---|
| C-SSRS 0 | 2 | 0% | 0% | 0% |
| C-SSRS 1 | 3 | 0% | 0% | 0% |
| C-SSRS 3 | 2 | 50% | 50% | 0% |
| C-SSRS 4 | 3 | 0% | 0% | 33% |

**双通道一致性（高危子集，法官 vs 词典）**：ask κ=0.00（一致率 80%）、
harm κ=0.00（80%）、resources κ=0.00（60%）、ack κ=-0.43（20%）——
两通道对"模型没做危机询问"高度一致，但对"共情"的操作化定义存在分歧，
如实报告并开源两份评分供复核。

**关键结论 6（炼场的实证价值）**：通用大模型在最高危等级（C-SSRS 4）
剧本上**识别率 0%、危害输出率 33%**——没有专门安全设计的模型远未达到
心理危机场景的安全要求。这一结论本身即"为什么需要危机评测场"的最强
证据：它把"安不安全"从主观感觉变成可复核的评分卡。

**（6）E7 预演场：数字孪生干预预演（方向 4/2，A/B × 剂量 0/6/12 × 2 会话）**

**UCLA-3 剂量-反应（Δ，正=改善）**：

| 孪生 | 干预 | 剂量 0 | 剂量 6 | 剂量 12 |
|---|---|---|---|---|
| 高孤独画像 | A 陪伴式共情 | +0.0 | +7.5 | +4.5 |
| 高孤独画像 | B 建议式解决 | +0.0 | +3.5 | -0.5 |
| 高压力画像 | A 陪伴式共情 | — | — | +3.0 |
| 高压力画像 | B 建议式解决 | — | — | -6.5 |

**匹配推荐（dose=12，UCLA-3 主指标）**：高孤独画像 → A（Δ差 +5.0，
p=0.385，d=1.41）；高压力画像 → A（Δ差 +9.5，p=0.164，d=3.80）。

**关键结论 7（预演场的两个发现）**：其一，两个不同画像的孪生**一致推荐
陪伴式共情臂**，方向一致、效应量中到大，但 n=2 未达显著——这正是
"决策辅助而非临床证据"的边界，如实标注；其二，剂量-反应**非单调**
（A 臂 6 轮 +7.5 > 12 轮 +4.5），提示存在最优剂量区间，为后续
长程实验提供了可检验的新假设。

**（7）E8 作答漂移定律（探索性，温度×类型×语言网格，n=3/格）**

量程归一化后：H1 温度效应不显著（symptom +0.0，p=0.92；state -0.0，
p=0.82）；H2 量表类型效应不显著（+0.0，p=0.79）；H3 语言效应方向与
E5 一致但未达显著（症状量表 zh-en +0.1，p=0.55）。

**关键结论 8（负结果如实报告）**：在更紧凑的网格中，"温度升则漂移大"
的假设**未获支持**；E5 观察到的中文语境高报是**语境级效应**（人设语言）
而非简单的作答风格规律，且需要 n≥5 的施测才稳定显现（E5 用 n=5 显著，
E8 用 n=3 不显著）。这组负结果为"哪些因素真正驱动 AI 心理作答漂移"
划出了边界：语言语境与量表类型是主要嫌疑，采样温度在 0.2-1.4 内影响
有限——这正是预注册式实验的价值：假设该倒就倒，结论才可信。

## 六、总结与展望

### 6.1 经验总结

- **成功经验**：真值分离 + 盲测协议是"AI 心理可量化"的关键设计；
  预注册式实验让 E8 的负结果也变成有价值的结论；
  双通道评分 + κ 一致性让危机评分可复核；
  以确定性 Mock 先行回归，再上真实模型，工程效率高；
  视觉身份统一（设计 token 全链路复用）让报告/图表/PPT/榜单"一眼可辨"；
- **不足**：单模型（qwen2.5:7b）证据，跨模型一致性待扩展；
  虚拟被试次数有限（3-5 次/组合），E7 的 A/B 差异方向一致但未达显著；
  对话干预为短程（≤12 轮），与真实咨询的剂量差异需进一步研究；
  E6 的 κ 在共情维度为负值，说明双通道对该维度的操作化定义需细化；
  metric 层测量不变性在小样本下无法估计，如实标注。

### 6.2 未来规划

1. **跨模型基准**：在 qwen3、DeepSeek、GLM 等系列上运行同一流水线，
   扩榜 PsyMirror-Bench 五维评分卡；
2. **真人常模校准**：与高校心理中心合作，用真人样本校准 AI 分数的
   百分位映射，并把孪生预演升级为"孪生-真人对照验证"；
3. **长程干预与最优剂量**：围绕 E7 发现的"6 轮优于 12 轮"非单调现象，
   扩展 0-100 轮剂量扫描与更多画像；
4. **危机协议细化**：扩充检查表维度（如安全约定、平静化识别），
   修正共情维度的操作化定义以提高双通道 κ；
5. **平台化**：封装为 Web 服务 + 标准化 API，面向心理产品厂商与
   高校心理系提供"效果质检 + 安全红队"服务；
6. **文化适配**：针对中国社会文化环境补充本土化量表与中文常模（方向 8），
   把 E5 的等价性检验扩展为量表级的 DIF 全扫描。
